# BUMIHIJAU-Gamed Based Learning Mobile App Quiz 
# 🌱 BumiHijau

## Project Description

**BumiHijau** is an Android mobile application developed to promote environmental awareness and encourage sustainable recycling habits through interactive learning and gamification. The application provides educational recycling content, quizzes, rewards, and community engagement features to motivate users to practice proper waste management in a fun and engaging way.

---

## ✨ Features

* 👤 User Authentication (Login & Registration)
* ♻️ Recycling Guide & Educational Content
* 🎮 Gamification System
* 📝 Interactive Quizzes
* 🏆 Leaderboard
* 🎁 Reward & Point System
* 📈 User Progress Tracking
* 👥 Community Events & Activities
* 🔔 Notifications
* 📱 User-Friendly Interface
